# CleanTwin - AI-Powered Facade Cleaning Quality Assessment

## Description

CleanTwin is an innovative solution that leverages artificial intelligence and drone technology to assess and monitor the quality of facade cleaning operations. The system provides real-time analysis and digital twin visualization to ensure cleaning standards are met efficiently and effectively.

## Project Structure

```
clean-twin/
├── backend/          # Backend API services
├── frontend/         # Web-based user interface
├── ml_training/      # Machine learning model training
├── drone_integration/ # Drone communication and control
├── docker/           # Docker configuration files
└── docs/             # Project documentation
```
